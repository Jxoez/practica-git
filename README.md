# Práctica Git

Proyecto mínimo (contador en HTML/CSS/JS) pensado solo para practicar el flujo
de trabajo de Git y GitHub: cambios, commits y push.

## Cómo usarlo

1. Descomprime la carpeta en tu equipo.
2. Sigue la guía de pasos que te dio Claude para inicializar el repo,
   hacer commits y subirlo a GitHub.
3. Une los ejercicios sugeridos abajo para generar varios commits distintos.

## Ejercicios sugeridos (cada uno = un commit)

1. Cambia el color de fondo en `style.css`.
2. Agrega un botón "Reiniciar" que ponga el contador en 0.
3. Cambia el título de la página.
4. Agrega tu nombre como autor en este README.
5. Corrige algún "bug" a propósito (ej. que sume 2 en vez de 1) y luego
   arréglalo en otro commit.
